# FZU 校园失物招领平台

## 项目简介
本项目是“校园失物招领”Web 应用，基于第一次结对作业的原型设计，完成了发布寻物/招领信息、浏览、搜索、查看详情及标记状态等核心功能。纯前端实现，使用 localStorage 存储数据，无需后端。

## 使用说明
1. 下载本项目所有文件。
2. **使用谷歌浏览器（Chrome）** 打开 `index.html`。
   - 如果直接双击无法运行，请安装 VS Code 的 `Live Server` 插件，右键 `index.html` -> `Open with Live Server`。
3. 页面加载后，默认在首页，显示“无相关信息”。
4. 点击底部“+”按钮 -> 填写物品信息 -> 点击“确认发布”。
5. 发布成功后自动回到首页，可以看到你发布的信息。
6. 在顶部搜索框输入关键词，列表会实时过滤。
7. 点击“寻找物品”/“寻找失主”切换分类。
8. 点击卡片进入详情页，查看完整信息和联系方式。
9. 点击底部“我的” -> 管理你的所有发布，点击“标记为已找到/已归还”更新状态。

## 与第一次结对原型的对应关系
| 原型模块 | 本次实现 | 差异说明 |
|--------|--------|--------|
| 首页列表 | 首页视图 `#itemList` | 原型有分页，本次改为一次性全部显示 |
| 发布页 | `#publishView` 视图 | 原型是独立页面，改为单页多视图切换 |
| 详情页 | `#detailView` 视图 | 增加状态更新入口（放在“我的”页面） |
| 搜索栏 | `#searchInput` | 保持一致 |

## 技术说明
- 原生 HTML + CSS + JavaScript，无第三方框架。
- 数据存储在浏览器 `localStorage`，关闭页面后再次打开数据不丢失。
- 单元测试：打开 `tests/test.html` 运行，测试核心逻辑函数。
